# 整数量化核心公式

> **定位**：本目录收集整数量化数学验证所依据的核心公式与推导，**纯数学表述，不涉及任何具体项目实现**。
> **约定**：
> - `Δ`：量化步长；`b`：位宽（bits）；`m_f`：输入最大值（scale 基准）。
> - 位精确（bit-exact）指公式在整数/浮点机器精度下严格成立，零容差。
> - 符号 ∀ 通用，不绑定任何实现。

---

## 1. 量化基础

### 1.1 对称整数量化

对称整数量化使用对称整数范围 `[-(2^(b-1)-1), 2^(b-1)-1]`（丢弃 `-2^(b-1)` 一档以保持对称）：

```
scale = m_f / (2^(b-1) - 1)
```

- 8 位：`Δ = m_f/127`，级数 `q ∈ [-127, 127]`（255 级，对称）
- 16 位：`Δ = m_f/32767`，级数 `q ∈ [-32767, 32767]`（65535 级，对称）

> 对称性导致 `Δ = m_f/(2^(b-1)-1)` 而非 `m_f/2^(b-1)`，是方差比数值差异（如 66568 vs 65536）的根源。

### 1.2 量化与反量化

```
q  = round(x / Δ)          # 量化
x̂ = q · Δ                  # 反量化（dequantize）
ε = x − x̂                  # 量化误差（残差）
```

## 2. 随机舍入（Stochastic Rounding, SR）

### 2.1 无偏性

随机舍入是无偏的：

```
E[noise] = 0
```

### 2.2 方差

Bernoulli 随机舍入的单步噪声方差（均匀步长 Δ）：

```
Var(noise) = Δ² / 6
```

加性均匀抖动 + 确定性 round 的方差（与 Bernoulli SR 同源，本组验证修正口径）：

```
Var = Δ² / 6
```

> 经典区分：确定性 round 的均匀量化误差方差为 `Δ²/12`；随机舍入（Bernoulli）为 `Δ²/6`。本组验证发现"均匀抖动 + round"实为 `Δ²/6` 而非 `Δ²/12`，与 Bernoulli SR 同源。

### 2.3 方差随位宽缩放

```
Var ∝ Δ^b，幂指数 b = 2，比例常数 a = 1/6
```

### 2.4 步长比（跨位宽方差比）

对称量化下，8 位与 16 位步长比：

```
Δ_8 / Δ_16 = m_f/127 ÷ m_f/32767 = 32767/127
Var(Q_8) / Var(Q_16) = (Δ_8/Δ_16)² = (32767/127)² ≈ 66568
```

- 若 8 位用非对称范围 `[-128, 127]`：`Δ_8 = m_f/128`，方差比退化为 `(32767/128)² ≈ 65536`
- 对称（实际）实现下正确方差比为 **66568**

### 2.5 clip 引入 DC 分量

clip 后噪声期望不再为零：

```
clip 后 E[noise] ≠ 0
```

例如 1% clip 即可使 `E[noise] = -0.125`（约 `-3.2Δ`），破坏白噪声前提。

## 3. 整数位操作

### 3.1 位拆分可逆

整数 `value` 拆分为高/低位再拼接严格还原：

```
value = high · 2^p + low
high = value >> p
low  = value & mask
```

两种重建形式 bit-exact 等价：
```
(high << p) | low  ≡  high · 2^p + low
```

### 3.2 多精度层次拆分（1:N 解释）

任意 `split_bits` 下，`value` 分解为若干部分再按位权还原：

```
value = Σ_k part_k · 2^(k·b)
```

典型层次：`int32 → {16, 8, 4}`（default）、`64 → {32, 16, 8, 4}`、`8 → {4}`。

### 3.3 多精度拆分点积

多输出/单融合/一般化形式下，拆分点积与原始点积数值等价（bit-exact）：

```
fused = Σ_i w_i · x_i
```

### 3.4 信息分离（位带依赖）

多输出层各只读指定输入位带，无跨带泄漏（正交/低冗余）：

- fine 层仅依赖低×低位带，且 `cross = coarse = 0`
- coarse 层仅依赖高×高位带，且 `fine = cross = 0`
- cross 层依赖混合带（高位×低位 + 低位×高位分别贡献）

尺度分离：`coarse·2^32 / fine` 贡献中位 `6.29e7`，`/cross·2^16` 贡献中位 `2.16e4`。

## 4. 精度分配

### 4.1 位宽与误差

量化误差随位宽指数衰减（bits 是主杠杆）：

```
ε(b) = c / (2^b − 1)
```

log-log 拟合验证：`log ε vs log(2^b−1)` 斜率 `k = −1.0026`（R² = 0.999987）。

### 4.2 位宽翻倍的精度提升

位宽翻倍 → 误差按 `2^b` 缩放：

```
16→32 位：提升 2^16 = 65536 倍（实测 65622×）
8→16 位：提升 2^8 = 256 倍（实测 257×）
```

### 4.3 贪心位宽分配 = 全局最优（M-凸性）

贪心边际分配与全局最优（拉格朗日/DP 回溯）的 gap 精确为 0：

```
gap = 0
```

### 4.4 成本信号须含维度因子

allocate 成本信号须含输入维度因子：

```
c = ‖grad‖₂² · in_dim
```

缺失维度因子时分配次优（误差劣化 1.19~6.50×）；分配 bits 与 `in_dim` 的 Spearman `ρ = 1.0000`（强正相关，可辨识）。

### 4.5 逐元素精度选择

重要性越高拆分越细（阈值语义）：

```
v < 100    → 16 位
100 ≤ v < 1000 → 8 位
v ≥ 1000   → 4 位
```

每元素按重要性选粒度，重建精确（粒度数随重要性单调细化）。

## 5. 噪声整形（delta-sigma / 误差反馈）

### 5.1 传递函数

N 阶误差反馈等价于 delta-sigma 调制：

```
NTF(z) = (1 − z⁻¹)^N
STF(z) = 1
```

### 5.2 低频抑制

1 阶误差反馈在低频将量化噪声抑制（实测 `1167× ± 34×`）；权重噪声传递函数：

```
TF_weights = (1 − z⁻¹)^(N−1)
```

1→2 阶权重 DC 功率比 `657740×`。

### 5.3 clip 放大

clip 破坏白噪声前提后，噪声被整形放大（低频功率）：

```
低频功率放大 ≈ 10⁵ 倍（实测 90327× ± 11518×）
```

无反馈时低频功率 `≈ 4.88`。

### 5.4 分离残差反馈

分离残差反馈下无放大：

```
分离反馈 低频/无反馈 = 1.000 ± 0.000
标准反馈             = 90327×（对照成立）
```

## 6. 梯度恒等式

### 6.1 残差反向传播恒等梯度

```
dy = dy_act · W^T + dy_skip
```

含 skip 路径时解析梯度与数值梯度 `max|Δ| = 5.5e-10`（机器精度）；去掉 skip 后误差上升至 `2.8e-1 ~ 4.5e+0` → skip 路径必须保留。

### 6.2 损失梯度归一化

损失梯度除以总元素数：

```
∂L/∂y = (·) / N
```

错误地除以 `batch_size` 会引入 `D` 倍尺度偏差，证明必须除以总元素数。

### 6.3 交叉熵梯度

```
∂L/∂logits = (softmax − one_hot) / batch_size
```

解析与数值梯度 `max|Δ| = 1.2e-10 ~ 3.2e-10`（机器精度）；类别索引与 one-hot 两种标签形式等价；梯度行和为零（CE 冗余性质）机器精度成立。

## 7. 相对误差均匀性（量化器性质）

### 7.1 线性量化相对误差

线性量化器的相对误差与 scale 无关，仅由位宽决定：

```
相对误差 ≈ 1 / (2^bits − 1)
```

### 7.2 非均匀精度分配定理

**定理**：要打破跨层"相对误差均匀"，必须实现跨层非均匀的精度分配。

| 配置 | 相对误差跨层 |
|------|------------|
| 均匀 bits + 均匀 scale | 均匀 |
| 非均匀 bits + 均匀 scale | 非均匀 ✓ |
| 均匀 bits + 非均匀 scale | 非均匀 ✓ |
| 均匀 bits + 均匀 scale + 误差反馈 | 仍均匀 ✗ |
| 均匀 bits + 对数刻度 | 更均匀 ✗ |

**推论**：非均匀 bits 与非均匀 scale 是两个正交的精度分配杠杆，可叠加使用。

## 8. 超度量性（证伪）

对 `log-half-normal` 分布三元组排序后，超度量不等式违反率：

```
违反率 = 100%（远 > 20% 判据）
违反幅度 p99 = 2.51（远 > 0.5 判据）
```

即：该类分布**不满足超度量性**（复现证伪成立）。

## 9. 深层残差放大（经验标度）

深层残差随深度指数放大（Jacobian 范数 > 1）：

```
相对残差 ∝ 深度（指数标度律，R² = 0.754）
每层放大因子 ≈ 8.8×（几何均值，> 1）
```

经验报道的总体放大 `~86×` 为配置相关的结构性结论（深层放大 + Jacobian > 1），非普适常数。
