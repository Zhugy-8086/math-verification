# 整数量化数学结论的独立数据验证计划

> **创建日期**：2026-08-13
> **定位**：对一套已冻结的整数量化数学结论，用 **NumPy 纯数据验证**（非神经网络训练）做严格复核。
> **验证方式**：正推 + 倒推 + 更大规模数据（详见 §2 方法论）。
> **执行策略**：结论数量多且每项都需 CPU 计算，故**排好顺序、逐步执行**，不一次性全做。
> **产物**：每个结论一个 `validate_*.py` 脚本 + 验证结论记录回本文档。

---

## 1. 背景与目标

在整数量化研究（多阶段数学验证）中冻结了大量数学结论。这些结论目前主要靠**神经网络训练实验**间接验证。本计划的目标是：

1. **纯数据层面**独立复核这些结论——不跑网络，只对合成数据做统计/代数/频域/梯度验证。
2. **正推**：从公式/参数正向计算出理论值，与实测统计对比，验证理论是否正确。
3. **倒推**：从实测数据反向拟合出公式系数，验证能否还原冻结的参数（如随机舍入的 Δ、贪心的 bits 分配、噪声整形传递函数的极点位置）。
4. **更大规模**：用比之前更大的 N / 层数 / 维度做压力验证，暴露 clip、溢出、精度损失等隐藏问题。
5. **一致性**：把验证结果与既有的验证脚本、报告结论比对，确认无矛盾。

## 2. 验证方法论（三种方式定义）

对每个结论，尽量覆盖以下三种方式（标注每项适用哪几种）：

### 2.1 正推（Forward Derivation）
- 给定公式和参数 → 计算出**理论期望值**。
- 用 NumPy 生成大规模合成数据 → 蒙特卡洛实测统计量。
- 判定：`实测 / 理论` 是否落在容差内（通常 ratio ∈ [0.99, 1.01]）。

### 2.2 倒推（Reverse Derivation）
- 从实测数据**反向拟合**公式中的未知参数。
- 例：从随机舍入噪声方差反解 Δ；从 bits 分配反解成本信号；从频域响应反解噪声整形传递函数极点。
- 判定：拟合出的参数是否与冻结值一致（误差 < 1e-2 或 < 1%）。

### 2.3 更大规模（Larger Scale）
- 将 N / 层数 / 维度 / 位宽提高到原实验之上（如 1e6 样本、更多层）。
- 更大 N 降低蒙特卡洛采样误差（~1/√N），使 ratio/参数估计更精确，能暴露更小的真实偏差——这是严谨性的正向来源。
- 但必须区分两类偏差：
  - **真实统计偏差**：结论本身在更大规模下不成立（有意义的发现）；
  - **数值精度伪影**：float32 累积误差、clip 尾部元素主导方差等，不代表结论错误。
- 判定：结论在更大规模下是否仍成立，或暴露新的边界条件；并明确标注所用浮点精度（float64 / float32）。

### 2.4 结论性质分类与对应判定标准（关键严谨性升级）

不同结论的性质不同，**不能统一用 ±1% ratio 判定**。所有结论先归入三类，再选用对应判定标准：

| 类别 | 含义 | 例子 | 判定标准 |
|------|------|------|---------|
| **T（定理/恒等式）** | 位精确或代数恒成立 | int12 可逆、位拆分可逆、int16 视角重构、量化公式 | **严格相等**（bit-exact / 机器精度），零容差 |
| **S（统计定律）** | 随机过程的理论期望/分布 | SR 方差=Δ²/6、SR 无偏性 E[noise]=0、clip DC 分量、Δ²/12 | **假设检验 + 置信区间**，容差随 N 收紧 |
| **E（经验标度律）** | 由实验拟合的常数/关系 | 精度提升倍数、power law 指数、深层放大倍数 | **验证关系/标度**而非常数，报告 CI 与拟合优度 |

### 2.5 统计类（S）的严谨性要求

对 S 类结论，禁止单点估计。至少做到：
1. **多随机种子**（≥ 5 个 seed），报告 `mean ± std`，而非单次 ratio；
2. **置信区间**：bootstrap（≥ 1000 次重采样）或解析标准误；
3. **假设检验**：
   - 无偏性 `E[noise]=0` → t 检验（或报告 E±2σ 是否含 0）；
   - 方差比 `Var_empirical/Var_theory=1` → 基于样本方差的卡方/F 分布检验；
4. **容差随 N 收紧**：容差 = 理论标准误 × 系数，即 `|ratio-1| ≤ k·sqrt(2/(N-1))` 之类，而非固定 ±1%。N 越大，允许偏差越小。
5. **明确浮点精度**：声明统计是在 float64 还是 float32 下进行。

### 2.6 倒推（Reverse）的严谨性要求

倒推不能只是"大概能反解出参数"。要求：
1. **可辨识性**：先说明参数能否唯一反解（如从 Var(noise)=Δ²/6 反解 Δ，Δ>0 唯一）；
2. **回归方法**：明确用最小二乘 / 幂律 log-log 拟合 / 频域传递函数拟合；
3. **拟合优度**：报告 R²、残差分析、参数的标准误与置信区间；
4. **参数还原判定**：反解参数与冻结值比较，给出相对误差 + 该误差的统计显著性。

### 2.7 证伪 vs 证实（Falsification vs Confirmation）

部分冻结结论本身就是**证伪结论**（如超度量性违反率 100%、误差反馈不作为训练增强器）。对这些结论，验证目标是**复现证伪**——确认其确实不成立/确实违反，而非试图证明它成立。在 §3 表格中标注每个结论是"证实"还是"复现证伪"。

### 2.8 一致性（Consistency）的量化定义

"与之前计算结果一致"必须量化，不可含糊：
- 若之前结论是**具体数值**（如 ratio≈1.0000）：当前结果落在其 ±1%（或更严的统计容差）内即一致；
- 若之前结论是**关系/标度**（如 power law）：当前拟合的参数与原参数的置信区间重叠即一致；
- 若之前结论是**区间**（如 CI）：当前点估计落在原 CI 内即一致。

**判定标准（按性质类别）**：
- **T 类**：`np.array_equal` / 机器精度严格相等，零容差 → PASS；否则 FAIL。
- **S 类**：多 seed 报告 `mean±std`，用假设检验（t / 卡方 / F）+ bootstrap CI，容差随 N 收紧（`k·√(2/(N-1))`）→ 通过检验则 PASS。
- **E 类**：验证关系/标度（log-log 拟合参数 a、b），报告 R² 与参数 CI，CI 与冻结值重叠则 PASS。
- **更大规模**：在 N 增大后估计稳定（不漂移）为 PASS；若漂移/发散，标记为"暴露边界条件"，并区分**真实统计偏差** vs **数值精度伪影**（§2.3）。

## 5. 执行顺序与依赖

```
阶段 1 (随机量化统计)   ← 起点，独立，秒级，建立可信基线
   ↓
阶段 2 (位操作代数)     ← 独立，秒级
   ↓
阶段 3 (精度分配)       ← 依赖阶段 1 的方差统计作为成本信号
   ↓
阶段 4 (频域噪声整形)   ← 依赖阶段 1 的噪声性质（白噪声/clip 前提）
   ↓
阶段 5 (梯度恒等式)     ← 依赖阶段 3 的精度/成本概念
   ↓
阶段 6 (网络数学性质)   ← 最重，最后执行
```

**执行节奏**：一次执行 1 个阶段（或 1-2 个结论），每完成一个阶段把结果记录回本文件 §6，再进入下一阶段。不批量并行（避免 CPU 过载与结果混杂）。

1. **#4 抓错**：纠正了既有结论#4 的口径混淆——均匀抖动+round 的方差实为 Δ²/6（非 Δ²/12），与 Bernoulli 随机舍入同源。

**方法论观察（供后续参考）**：
- **超大 N 统计显著性伪影**（#1/#2）：N 达 10⁶ 时 z/t 统计量显著（z=-7.73、t=-2.66），但实际偏差 <0.1%，随 N 收敛——是大样本量下的伪影，非真实偏差。判据应看相对量级而非 p 值。
